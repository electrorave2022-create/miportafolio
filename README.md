# Portafolio Personal - César Edyberto Chiroy Bocel

Portafolio web profesional desarrollado como proyecto final para el curso de **Introducción a la Programación Web** en la **Universidad del Valle de Guatemala (Campus Altiplano)**.

## 🚀 Tecnologías Utilizadas
* **Backend:** Python / Django (Vistas, rutas y plantillas).
* **Frontend:** HTML5 semántico y CSS3 puro (variables `:root`, diseño adaptable con Grid y Flexbox, modo oscuro).
* **Interactividad:** JavaScript nativo (menú hamburguesa móvil, validación de formulario de contacto con mensajes en pantalla y filtro dinámico de proyectos).
